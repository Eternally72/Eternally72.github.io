02 Featured Project

Active exploration

AUTOMATED CODE REVIEW

自动代码审查

让每一次代码变更，在进入人工评审前，先得到一轮理解上下文、识别风险并给出可执行建议的自动审查。

项目围绕 Pull Request 工作流展开，重点探索如何组合变更解析、仓库上下文、工程规则与大模型能力， 将“泛泛而谈”的回答变成定位明确、理由充分、方便开发者采取行动的审查意见。
