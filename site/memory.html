从一条事实，到长期偏好

原始信息作为 L0 原子记忆保存。高层记忆按证据逐层整合，并保留来源版本；不会用新的总结覆盖原始事实。

  1. L0

    原子记忆

    可独立理解的事实、事件、计划或决策。

  2. L1

    主题记忆

    整合同一主题或局部事件中的相关信息。

  3. L2

    领域记忆

    从多个主题中形成更稳定的领域认识。

  4. L3

    用户画像

    保留有持续证据支持的偏好、习惯与目标。

如何追溯一条总结的来源？

层级关系只连接相邻层级，生成版本保存当时使用的来源 ID 与版本。查询派生记忆时，可以沿这些引用回到原子事实，而不是把最新原文当成历史依据。

检索既看语义，也看明确条件

关键词与向量两路召回，通过 RRF 融合排序。用户、namespace、scope 和时间条件在数据库查询内生效，返回前再次核对记忆的可见性与版本。

  1. 限定范围确定身份、可见空间和结构化过滤条件。
  2. 两路召回PostgreSQL 词法检索与 pgvector 向量检索。
  3. 融合与复核合并候选，按配置重排，再检查状态和版本。
  4. 返回证据保留内容、来源、检索通道和降级原因。
向量服务不可用时怎么办？

混合检索可以降级为关键词检索，并明确返回降级原因。词法存储本身失败时返回错误，不把故障伪装成“没有找到记忆”。

信息会变化，记忆也需要维护

纠正

产生新事实并保留原始记录，让受影响的派生内容失效并重新整合。

归档与恢复

将暂不使用的信息归档；恢复时核对完整性与版本，不覆盖数据库中的新状态。

遗忘

清理指定事实及相关副本、纠正链与派生依赖，审计记录不保留正文。
